# Markdown files in a personal OneDrive folder for the MVP

Cowork can read and write OneDrive files and cannot see the local disk, and another person needs to run the same layout in their own OneDrive. The MVP stores each Reply, each Task, and each Meeting as one Markdown file in a fixed folder. An email Source stores its Outlook on the web address in that file. The app opens the address. It does not call Microsoft Graph in this version. The app is the list. Excel and Planner were rejected: Excel is a second list Cowork must not fight for locks, and Planner plans live in a Microsoft 365 group and cannot hold a Reply. A database is the intended later store, so the app reads and writes through a repository boundary and does not treat the folder layout as permanent. Cowork cannot delete OneDrive files, so finishing an item sets a status and leaves the file in place.
