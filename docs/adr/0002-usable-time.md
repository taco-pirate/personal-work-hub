# Usable time is Focus Time and empty gaps inside the workday

The calendar exists to show where owed work can go. Usable time is Focus Time, plus gaps with no Meeting, and only the portion inside the workday. The workday starts as Monday through Friday, 8:00 to 5:00, in the user's time zone, and the user can change it. Personal is outside the work day. Operating Reviews, 1:1s, Working Sessions, Projects, Leadership, Operational Support, and Uncategorized consume the day. Overlapping meetings count once. An Accepted meeting wins those minutes over a Tentative one, and then the winner's category decides whether the minutes are usable. A Tentative meeting with nothing overlapping it still consumes the day by its category. A meeting the user has not answered counts as Tentative, and a meeting the user organized counts as Accepted. Declined and canceled meetings do not consume time. Teams presence never changes the day. A Busy event follows its category even when the user is the only attendee. A meeting shown as Free or Working elsewhere does not consume time. An all-day event consumes the workday only when the user Accepted it and it shows as Busy or Out of office. An all-day event shown as Working elsewhere does not. The user's category choice sticks.
