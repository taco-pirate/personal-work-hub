# Usable time is Focus Time and empty gaps inside the workday

The calendar exists to show where owed work can go. Usable time is Focus Time, plus gaps with no Meeting, and only the portion inside the workday. The workday starts as Monday through Friday, 8:00 to 5:00, in the user's time zone, and the user can change it. Personal is outside the work day. Operating Reviews, 1:1s, Working Sessions, Projects, Leadership, Operational Support, and Uncategorized consume the day. Overlapping meetings count once. The user's category choice sticks.
