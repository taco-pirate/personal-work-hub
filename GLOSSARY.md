# Personal Work Hub

The private work of one person: what they owe, and what they will do next. A colleague has their own hub.

## Language

### Work owed

**Reply**:
The answer owed when a message asks the user for a decision or a reply. It stays owed until the user marks it sent.
_Avoid_: Ready reply, draft reply, email response

**Task**:
A deed the user owes that is not an answer owed to someone. It stays owed until the user marks it done.
_Avoid_: Action item, actions, to-do, follow-up, commitment, deed

**Action address**:
The link where a Task's deed happens. Cowork fills it only when the email contains one clear link to that deed, and leaves it empty when there is none or more than one. It is never the Outlook address of the Source.
_Avoid_: Portal link, URL

**Comment**:
A note added to an owed Reply or Task when a later message chases that same item. It keeps the Outlook on the web address of the chasing message. It does not create another Reply or Task, and it does not change a Reply the user has edited.
_Avoid_: Follow-up, update, nudge

**Escalated**:
An owed Reply or Task that a later chase squeezed, by moving the deadline earlier, saying it is overdue or blocking someone, or coming from a different person. A reminder from the same sender with the same deadline is a Comment only. The flag stays until the user marks the item Done or dismisses it.
_Avoid_: Urgent, overdue, follow-up, blocked

**Owed**:
A Reply or Task in Drafted, In Progress, Blocked, or Ready that the user has not deferred. A Deferred item is owed again on the date the user chose.
_Avoid_: Open item, inbox, active, actions

**Drafted**:
A Reply or Task that has been filed and that the user has not started.
_Avoid_: Drafting, open, to do, backlog

**In Progress**:
A Reply or Task the user has started and has not finished.
_Avoid_: Doing, active, started

**Blocked**:
A Reply or Task the user has marked because they cannot proceed.
_Avoid_: Stuck, waiting, escalated

**Ready**:
A Reply or Task with nothing left but the closing act. A Reply is Ready only when every promised fact was decided by the user.
_Avoid_: Approved, complete

**Done**:
A Reply the user has sent, or a Task the user has finished. It stays on the board through the workweek in which that happened.
_Avoid_: Sent, closed, complete

**Archived**:
A Done Reply or Task kept in the folder and off the board after the workweek in which it was finished.
_Avoid_: Deleted, removed

**Dropped**:
A Reply or Task the user will not do. It is not Done. The file stays, and the item leaves the Desk, the list, and the board.
_Avoid_: Deleted, cancelled

**Deferred**:
A Reply or Task the user has set aside until a date. It leaves the Desk, the list, and the board until that date, then returns in the state it left and is owed again.
_Avoid_: Snoozed, postponed

**Due**:
The time a Source states that the work is owed. When the Source names a day and no time, Due is the configured end time on that calendar date. When the Source states no date, or two dates that disagree, there is no Due.
_Avoid_: Deadline, target

**Source**:
The message or meeting an item came from. An email Source includes the Outlook on the web address of that message, and a Meeting includes the Outlook on the web address of that event. Items that share a Source are linked, and finishing one does not finish the others.
_Avoid_: Thread, original email

### Calendar

**Meeting**:
A block of time on the user's calendar with exactly one category. When the user sets the category, that choice stays.
_Avoid_: Event, appointment

**Operating Review**:
A recurring meeting that reviews how a service or operation is running.
_Avoid_: Ops review, service review

**Focus Time**:
Time held for the user's own work, with no collaboration expected.
_Avoid_: Focus block, heads-down time

**1:1**:
A meeting with exactly one other person about that person, their work, or the relationship with the user.
_Avoid_: One-on-one, check-in

**Working Session**:
A meeting in which the attendees make or decide something during the meeting.
_Avoid_: Workshop, working meeting

**Projects**:
A meeting about the status, plan, or steering of a named project.
_Avoid_: Project status, steerco

**Leadership**:
A meeting of more than two people about direction, staffing, or decisions the user attends as a leader.
_Avoid_: Leadership sync, staff meeting

**Operational Support**:
Live help for the running operation, including an incident bridge or hands-on support.
_Avoid_: Incident bridge, support call

**Personal**:
Time that is not work.
_Avoid_: Private, out of office

**Uncategorized**:
A Meeting Cowork could not place in a category. It stays unlabeled until the user chooses one.
_Avoid_: Unknown, other

**Usable gap**:
At least 15 minutes inside the workday, through the last workday of this week, that no consuming Meeting occupies. Free and Working elsewhere stay usable even when the Meeting is Uncategorized.
_Avoid_: Free time, opening
